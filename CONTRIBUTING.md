# Contributing

Thanks for helping improve Meshy Turntable.

1. Fork the repository and create a branch for your change.
2. Run `npm ci` and `npm run dev`.
3. Keep the preview/export behavior consistent and preserve the three background
   choices. Avoid introducing model uploads or external processing without an
   explicit design discussion.
4. Run `npm run build` and `npm test` before opening a pull request.
5. Explain the problem, the behavior you changed, and how you checked it.

For bug reports, include the browser, export format, quality, background, and
reproduction steps. If the problem concerns framing or textures, include a small
GLB only when you have permission to publish it. Do not include credentials,
private models, or personal information.

The application code you contribute is distributed under the project's MIT
license. Keep any required third-party license notices with contributed code.
